# 任务背景
Random Door (任意门) 是一个探索中国城市文化的黑客松产品。目前已完成精美的前端开发、后端核心 API 开发，并**完成了前后端的全面联调**。
前端栈：React + Vite + Tailwind + Zustand + 高德地图 3D + Pannellum 360全景。
后端栈：Go + Gin + GORM + MySQL。

# 关键决策记录与排雷（已尝试过的死路）
1. **视觉风格探索**：最终确认了“新中式雅白极简”配合半透明毛玻璃悬浮效果，放弃了暗黑赛博风格。
2. **地图选型危机（核心排雷）**：
   - 曾短暂尝试将底层迁往百度地图 API GL，以期直接调用百度的实景车拍全景。
   - **结果：已废弃**。百度全景画质较差、天色灰暗且易出现路人马赛克，与高端调性相冲。
   - **最终定稿**：宏观继续采用高德 3D 地图；微观抛弃商业街景 API，改用前端 WebGL 库 (`pannellum-react`) 配合无版权的高分辨率（可达 8K）360° 等距圆柱投影摄影图。
3. **React 生命周期冲突**：曾将全景视图和地图视图进行组件互斥挂载，导致切回大地图时高德 SDK 崩溃报错。
   - **最终定稿**：`MapCanvas` 被移入 `<main>` 底层绝对定位常驻，不随全景挂载而卸载，退出全景时能完美保留先前视角。
4. **后端架构约束**：严格遵守文档，不使用 Redis/Kafka/ES，采用单体结构。
5. **后端启动与连接**：外部 MySQL 远端连接 (`117.72.99.55:53306`) 已配通并创建数据库 `city_roam`。
6. **前后端联调完成**：解决了前后端字段定义不一致问题 (`figures` vs `characters`)，修正了 `GameStore` 传参遗漏，对接了真实 `api.chat` 与生成赛博打卡功能，挂载了全景成就墙 `AchievementPage`。
