# 任意门产品需求文档

## 1. 产品定位

任意门是面向中国城市文化探索的互动 Web 产品。它不是传统攻略站，也不是单一 AI 聊天工具，而是把地图探索、随机漫游、城市内容、AI 人物对话、赛博打卡、猜城市挑战、个人足迹和成就系统组合成一个持续探索体验。

## 2. 核心用户价值

| 价值 | 说明 |
|---|---|
| 发现城市 | 在地图和城市列表中按地域、标签、搜索条件浏览城市。 |
| 随机惊喜 | 通过方向与距离随机生成下一站，形成大富翁式漫游。 |
| 文化互动 | 查看城市简介、地标、美食、方言和代表人物，并与人物进行 AI 对话。 |
| 生成记忆 | 上传照片生成城市打卡图，合成可下载海报。 |
| 社交传播 | 基于城市风光生成“猜一猜”文案和挑战链接。 |
| 长期收集 | 保存访问城市、打卡海报、成就进度和个人资料。 |

## 3. 已实现产品能力

| 模块 | 当前能力 |
|---|---|
| 首屏 | 品牌欢迎层，支持自由探索、任意门随机漫游、注册/登录入口。 |
| 地图 | 高德 3D 地图，城市 marker，地标 marker，搜索与筛选同步地图。 |
| 自由探索 | 点击城市写入 free visit，进入城市详情。 |
| 任意门漫游 | 游戏初始化、随机方向、随机距离、目标点计算、最近城市匹配、飞行动画、game visit。 |
| 城市详情 | 城市简介、标签、地标、美食、人物、方言、图片风光浏览、声景入口。 |
| AI 对话 | 后端组装 prompt 调 LLM，保留历史消息，前端右抽屉展示。 |
| 赛博打卡 | 自拍上传、场景参考图、异步生图任务、任务轮询/重试、确认打卡、海报下载。 |
| 成就 | 访问、打卡、城市标签、游戏访问、方向、距离等规则；自动解锁与成就墙展示。 |
| 个人资产 | 足迹城市、打卡海报、成就进度、匿名资料编辑。 |
| 评论弹幕 | 对地标/美食/人物发表评论并读取列表。 |
| 猜城市挑战 | 截图/图片生成文案，创建匿名挑战链接，好友提交答案。 |
| 后台 CMS | ADMIN_TOKEN 门控；城市、标签、地标、美食、人物、成就和媒体资产维护。 |
| 内容导入 | seed audit/bootstrap/sync，默认不覆盖数据库内容。 |

## 4. 产品原则

1. 到达方式可以不同，但城市探索体验共用同一套详情、对话、打卡与成就能力。
2. 数据库是内容事实源，seed 只作为受控初始化和维护工具。
3. AI 能力外部化，前端不接触模型 Key。
4. 后台优先保证内容可维护，不让产品依赖手改数据库。
5. 在 2C2G 单机部署约束下保持单体轻量，不引入重中间件。

## 5. 用户角色

| 角色 | 能力 |
|---|---|
| 游客 | 自动创建匿名身份，探索城市、对话、打卡、评论、解锁成就。 |
| 账号用户 | 注册/登录后保留匿名足迹、成就和打卡海报。 |
| 内容管理员 | 通过 ADMIN_TOKEN 维护城市内容、图片、标签与成就。 |

## 6. 内容策略

- 当前 seed 包含 35 座精选城市、每城 1-2 个地标、1-2 个美食、1 个人物、静态图片和部分声景。
- 生产内容应通过后台 CMS 维护；seed 导入前必须 audit。
- 城市数量校验允许 12-100，用于防止空 seed 或异常膨胀，不代表产品内容上限。
