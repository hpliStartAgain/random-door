# 任意门产品演示脚本

> 用于产品走查、客户演示或发布前自检。不是产品范围定义，真实验收以 `acceptance-criteria.md` 为准。

## 1. 演示前检查

- `.env` 已配置外部 MySQL、`VITE_AMAP_KEY`、`ADMIN_TOKEN`。
- 如需真实 AI，对应 `LLM_*` / `IMAGE_*` 已配置；否则确认 mock 生图链路可用。
- 数据库已有城市内容；空库先执行 `make seed-audit` 和 `make seed`。
- 后台 coverage 没有关键城市内容缺失。

## 2. 建议路径

### 00:00 - 01:00 品牌与入口

1. 打开首页。
2. 展示“任意门”品牌、自由探索、任意门随机漫游、注册/登录。
3. 进入主工作台。

### 01:00 - 02:30 自由探索

1. 在左侧搜索城市或选择标签。
2. 观察地图 marker 同步筛选。
3. 点击城市卡片或地图 marker。
4. 展示城市详情中的地标、美食、人物、方言。

### 02:30 - 04:00 任意门随机漫游

1. 切换到“任意门”。
2. 点击开启随机。
3. 展示方向、距离、目标城市和地图飞行/降落。
4. 进入目标城市详情。

### 04:00 - 05:30 AI 人物对话

1. 选择城市人物。
2. 在右侧抽屉提问。
3. 展示回答长度、合规口吻和历史上下文。

### 05:30 - 07:30 风光、猜城市与打卡

1. 点击地标或城市风光。
2. 展示沉浸图片视图与声景按钮。
3. 生成猜城市文案和挑战链接。
4. 上传自拍，创建生图任务。
5. 任务成功后确认打卡并下载海报。

### 07:30 - 09:00 成就与资产

1. 展示成就解锁动画。
2. 打开成就墙，查看已解锁、未解锁、进度。
3. 打开我的足迹，查看访问城市、海报、资料编辑。

### 09:00 - 10:00 后台 CMS

1. 点击后台入口并输入 `ADMIN_TOKEN`。
2. 查看 coverage。
3. 展示城市、标签、内容、成就和图片维护能力。

## 3. 网络或 AI 异常时

- LLM 失败：说明浏览、地图、评论、打卡主链路不依赖对话成功。
- 生图失败：展示任务状态与重试能力；mock 模式可保证链路闭环。
- 地图 Key 受限：使用已加载城市列表和后台内容说明产品能力，后续按 TODO 完成域名白名单配置。
