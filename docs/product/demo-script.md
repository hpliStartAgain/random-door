# 任意门 v1.0 — 评委演示脚本

> 目标总时长：≤ 8 分钟（留 2 分钟 Q&A 缓冲）
> 每 ~90s 一个 **WOW**，全程无卡顿。

---

## 演示前检查清单

- [ ] 后端已启动（`docker compose up -d` 或本地 `go run`）
- [ ] 前端 dev server 就绪（`npm run dev`）
- [ ] 高德地图 Key 已配置（`VITE_AMAP_KEY`）
- [ ] 已通过后台管理补齐至少 3 个城市的封面图
- [ ] 浏览器全屏模式（F11），字体缩放 100%
- [ ] 准备好一张自拍或人物照片（演示打卡用）

---

## 脚本正文

### 00:00 – 01:00｜品牌开场（WelcomeOverlay）

> 打开浏览器，全屏展示品牌页。

**说词（30s）：**
> "这是任意门——一个让你随机漫游中国城市的互动探索产品。
> 你不知道下一站是哪里，AI 帮你打开那扇门。"

**操作：**
1. 展示 WelcomeOverlay 的品牌标语与动效（约 10s）
2. 点击 **「随机漫游」**

---

### 01:00 – 02:30｜掷骰仪式（DiceConsole）★ WOW①

**说词（20s）：**
> "系统会以你的地理位置为起点，向随机方向掷骰——距离从几十到几千公里不等。"

**操作：**
1. 观察 **3D 骰子滚动**（5s）
2. 骰子停稳后，揭晓城市名称：**"目标——[城市名]！"**
3. 罗盘方向、距离 km 数 **指出给评委看**
4. 点击 **「降落」**
5. 指向地图：**飞行轨迹折线 + 镜头飞行动画 + 降落光环**（8s）

> "每次掷骰都是不同的惊喜——这就是任意门的核心乐趣。"

---

### 02:30 – 04:00｜城市探索（CityDetailPanel）

**操作：**
1. 点击 Sidebar 中目标城市卡片（真实封面图）
2. 展示 **城市详情**：封面大图、城市简介
3. 指出 **方言速记卡**："来看看这个城市的方言怎么说——"（念出方言示例）
4. 展示地标巡礼中的地标图片
5. 展示历史人物头像

---

### 04:00 – 06:00｜AI 跨时空对话（RightDrawer）★ WOW②

**说词（20s）：**
> "这个城市有一位 AI 复刻的历史人物，我可以和他/她直接对话。"

**操作：**
1. 点击人物卡片上的「与 TA 对话」
2. 抽屉弹出，展示 **打字机效果的自动开场白**（等待动画完成，约 5s）
3. 点击一个 **推荐问题 chip**，如"你最遗憾的事是什么？"
4. 等待 AI 回复（打字机逐字输出）
5. 再追问一条个性化问题（临场发挥）

> "注意这里的打字机效果，让对话像是真的穿越时空。"

---

### 06:00 – 07:30｜赛博打卡（CheckinFlow）★ WOW③

**说词（15s）：**
> "接下来是最有传播力的功能——AI 赛博打卡，把你的自拍和城市地标合成一张赛博大片。"

**操作：**
1. 返回城市详情，点击 **「生成赛博打卡」**
2. 选择地标（指出地标图）
3. 点击上传区域，选择准备好的自拍照片
4. 点击 **「✨ 生成赛博大片」**
5. 指向 **进度条**："AI 正在穿梭时空合成…"（等待约 10–20s）
6. 海报生成后展示：**"这就是你的专属赛博大片！"**
7. 点击 **「↓ 保存」** 演示下载

---

### 07:30 – 08:30｜成就解锁（AchievementUnlock）★ WOW④

**操作：**
1. 点击 **「✓ 确认打卡」**
2. **全屏庆祝弹层**出现：粒子撒花 + 成就徽章 + 音效（视觉冲击）
3. 等弹层自动关闭（或手动关闭）
4. 点击 Navbar **「成就墙」**，展示已解锁成就列表

> "每次打卡都会触发成就系统——12 个城市全部打卡后有终极成就等待解锁。"

---

### 08:30 – 10:00｜技术亮点总结 + Q&A

**快速技术亮点（1 分钟）：**

| 亮点 | 技术实现 |
|------|----------|
| 3D 掷骰仪式 | CSS 3D transform + keyframe 动画 |
| 飞行轨迹 | 高德地图 AMap.Polyline + moveAlong |
| AI 对话 | Go 后端 → 外部 LLM API，前端打字机逐字渲染 |
| 赛博海报 | 外部图像生成 API + 浏览器 Canvas 合成水印 |
| 成就系统 | 打卡原子事务（Go GORM 事务 + 规则引擎） |
| 后台管理 | ADMIN_TOKEN 门控，支持文件上传 + URL 粘贴 |

**预备 Q&A：**

- **Q：数据从哪里来？** → 种子数据（12 城 JSON），后台管理界面补图
- **Q：AI 费用怎么控制？** → 限流中间件（令牌桶，2 req/s）+ AI 超时保护
- **Q：用户数据安全？** → 匿名 ID，无登录，无个人信息收集
- **Q：能扩展城市吗？** → 加 seed JSON + 后台补图即可，无需改代码

## 备用路径（网络差时）

- AI 超时 → 展示已有打卡图片截图（备用素材）
- 地图 Key 无效 → 切换展示 Sidebar 城市列表 + CityDetailPanel
- 打卡 API 慢 → 提前截一张打卡海报图展示最终效果
